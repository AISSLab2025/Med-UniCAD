# README figure assets

The images in this directory are publication figures extracted from the
submitted Med-UniCAD manuscript for display in the repository README.

| File | Manuscript figure | README purpose |
|---|---:|---|
| `medunicad_architecture.png` | Figure 1 | Overall system and MoFX-Dense architecture |
| `qualitative_task_outputs.png` | Figure 2 | Segmentation and detection examples |
| `qualitative_report_generation.png` | Figure 3 | Cross-modality prediction and report-generation examples |

The routing-weight analysis and standalone agentic-interface figure are not
included because this repository is scoped to the final MoFX-Dense model,
training pipeline, and explicit-task inference API. The architecture image
retains the manuscript's full system context; the main README identifies which
components are implemented in this release.
